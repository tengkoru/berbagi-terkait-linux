# **Berbagi pengetahuan seputar linux**
Diinisiasi oleh Tengkoru

## Tujuan
Sebagai catatan pribadi dan juga sebagai bentuk kontribusi terhadap komunitas linux di Indonesia.

Saya harap kedepannya catatan ini akan bermanfaat bagi siapapun yang tertarik menggunakan linux untuk penggunaan sehari-hari maupun untuk pekerjaan kantoran mereka.

## Linux apa yang dicangkup di repository catatan ini?
Pada dasarnya penggunaan linux tidak terlalu jauh berbeda satu dengan lainnya, terutama jika digunakan untuk penggunaan sehari-hari. 
Namun, mungkin akan sedikit berbeda bila itu sudah menyentuh kearah folder sistem (/, adanya perbedaan perintah penginstalan, seperti pada turunan Arch linux menggunakan perintah 'pacman' atau 'yay', sedangkan distro linux turunan Debian menggunakan 'apt-get' atau 'apt'.
Disini saya akan berfokus pada turunan Debian, terutama MX Linux, karena itu distro linux yang saya gunakan saat ini. Kedepannya apabila ada yang mau berkontribusi pada repositori ini, dipersilahkan, saya sangat berterima kasih atas kontribusinya.
